# ISA-MAC

Implementação de uma nova **ISA (Instruction Set Architecture)** utilizando **MAL** e **MAC-1**, desenvolvida como parte de um trabalho acadêmico da disciplina de **Arquitetura de Computadores**.

## 🎯 Objetivo

Desenvolver uma nova **ISA**, definindo e implementando suas instruções, e realizar testes por meio do simulador **MALDE**.
O projeto tem como foco a compreensão prática do funcionamento de uma arquitetura de computadores, desde a definição das instruções até sua execução no simulador.

## 🛠️ Tecnologias e Linguagens

* **Assembly**
* **MAL (Micro Assembly Language)**
* **MAC-1**

## 🔧 Ferramentas

* **MALDE** — simulador utilizado para desenvolvimento e testes da ISA.
